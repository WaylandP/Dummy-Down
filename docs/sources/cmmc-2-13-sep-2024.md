inspected. A latest NIST catalog is not automatically the applicable CMMC
baseline. Use the versioned DoD snapshots here without silently upgrading them.

## Reproducible extraction and checks

`extract_model.py` reads bounding-box extraction of model section 2.4.1. It
separates left title and right statement cells using each table's actual column
coordinates. It asserts 149 unique records and 15/110/24 counts and independently
compares the complete ordered identifier inventory against ordinary layout text.

`extract_guides.py` reads only uppercase requirement headings in each guide body,
then extracts the paragraph ending before `ASSESSMENT OBJECTIVES`. It excludes
the table of contents, discussion, educational examples, assessment methods and
assessment-objective text. It asserts 15/110/24 guide counts and complete identity
agreement with the model.

The extraction used these Poppler commands. Contributors can verify the checked-in
quotes with `python3 scripts/verify-cmmc-sources.py --source-dir /path/to/pdfs`;
the verification requires Python 3 and Poppler `pdftotext`. These tools are optional
and are not part of the application build. The downloaded files must use the
filenames in the manifest and match their hashes.

Original extraction steps:

```sh
pdftotext -bbox-layout cmmc-model-213.pdf cmmc-model-213-bbox.html
pdftotext -layout cmmc-model-213.pdf cmmc-model-213.txt
pdftotext -layout cmmc-assessment-l1-213.pdf cmmc-assessment-l1-213.txt
pdftotext -layout cmmc-assessment-l2-213.pdf cmmc-assessment-l2-213.txt
pdftotext -layout cmmc-assessment-l3-213.pdf cmmc-assessment-l3-213.txt
python3 extract_model.py
python3 extract_guides.py
```

Physical wrapping is normalized; existing line-end hyphens are retained and
joined to their continuation. Underlining and italics are not reproduced, but
the DoD parameter **text values remain present**, including the Level 3 annual
training/plan updates, 24/7 SOC and 24-hour response-team statements.

139 model/guide requirement statements agree after whitespace normalization.
The other **10 are genuine publication wording differences**; they are retained
as both fields in every record and in `modelGuideWordingDifferences`:

`AT.L2-3.2.1`, `AT.L2-3.2.2`, `AU.L2-3.3.2`, `IA.L2-3.5.10`,
`MA.L2-3.7.3`, `PS.L2-3.9.2`, `CA.L2-3.12.3`, `SC.L2-3.13.1`,
`PS.L3-3.9.2e`, `SI.L3-3.14.3e`.

Use the **guide statement with its guide citation** as the displayed baseline
quote. Preserve the separate model statement and its citation. Do not label a
guide quotation as independently matched NIST verbatim text without comparing
that specific quotation with the applicable NIST publication.

all 149 identifiers. It does not establish reviewed educational explanations,
quiz coverage, evidence sufficiency, present contract scope, certification or
assessment readiness. Keep the existing README teaching example and its old
shareable identity separate. Add explanations and interactive learning as

unwritten lessons explicitly instead of synthesizing generic text to claim
coverage.
