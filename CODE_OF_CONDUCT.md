# Code of conduct

Cipher & Chalk is for people learning cybersecurity compliance, some of them
for the first time. Be the kind of colleague who makes that easier.

- Assume good faith, and explain rather than correct. A question about a
  control is never a dumb question.
- Disagree about sources, not people. Point to the publication, version and
  page.
- No harassment, insults, or personal or political attacks, and no sexualized
  language or imagery.
- Don't publish anyone's private information, and never post Controlled
  Unclassified Information, real evidence or credentials.

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
which applies in issues, pull requests, reviews and anywhere else someone
represents the project.

## Reporting

If someone breaks this code, tell the maintainer, @WaylandP, privately through
the repository's **Security** tab ("Report a vulnerability"); only the
maintainer sees those reports. The maintainer will respond, keep the report
confidential, and may edit or remove content, or block a contributor, as the
Contributor Covenant's enforcement guidelines describe.
